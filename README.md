# PT1 HellCorp - Proyecto de Análisis de Datos

## Estructura del Proyecto

```text
├── PT1.md
├── README.md
├── CSV/
│   ├── ORIGINALES/
│   │   ├── contratos.csv
│   │   ├── demonios.csv
│   │   ├── souls.csv
│   │   └── tormentos.csv
│   └── PROCESADOS/
├── fase_1_limpieza_integracion/
├── fase_2_consultas_sql/
├── fase_3_modelo_ia/
└── fase_4_informe_final/
```

## Descripción

Proyecto de análisis de datos de HellCorp dividido en 4 fases principales:

1. **Fase 1**: Limpieza e integración de datos
2. **Fase 2**: Consultas SQL
3. **Fase 3**: Modelo de IA
4. **Fase 4**: Informe final

Los datos originales se encuentran en la carpeta `CSV/ORIGINALES/` y los datos procesados se almacenarán en `CSV/PROCESADOS/`.
